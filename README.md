# Финальный проект
## Задание 1. Юнит-тесты
Протестировать программу, которая помогает заказать бургер в [Stellar Burgers]([https://skillbox.ru/media/](https://stellarburgers.education-services.ru/))

## Используемые технологии
- Java 11
- Maven 3.14.1
- JUnit 4.13.2
- Jacoco 0.8.14
- Mockito 5.20.0

## Протестированы классы
- Bun
- Ingredient
- Burger
